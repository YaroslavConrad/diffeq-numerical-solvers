# diffeq-numerical-solvers

Using Java to implement numerical methods for approximating first-order linear ODEs ($\frac{dy}{dx} = ax + by + c$).

## Files
* `EulerMethod.java` — Holds vars and the method which calculates the standard Euler's method approximation.
* `Runner.java` — Encodes user input that allows for all forms of questions referencing Euler's Method using first-order DE's.

## Run
```bash
javac *.java
java Runner
```
